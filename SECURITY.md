# Security Policy

This project controls a door buzzer, so security reports are taken seriously.

**Please do not open a public issue for vulnerabilities.** Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/Gimtiese/nuki-opener-link/security/advisories/new).

Please include what you found, how to reproduce it and, if you can, a suggested fix. This is a
hobby project maintained in spare time, so replies may take a few days.

Supported version: the latest commit on `main`.
